# Sidekick 1.0.0 Release Candidate 2

Version 1.0.0-rc.2 · Build 40 · Apple Silicon (arm64) · macOS 15.0 or later

## Changes

- Includes the Codex-inspired chat layout and model selector inside the composer from v1.0.0.
- Uses a shared 22-point corner radius for larger interface surfaces and a more subtle 8-point radius for chat buttons, including quick prompts, model controls, attachments, and message actions.
- Aligns Markdown code controls and conversation exports with the updated corner styling.
- Refreshes the README with current app screenshots and descriptions.
- Packages version-specific release notes and names the DMG separately from the stable v1.0.0 download.

## Download and install

Open `Sidekick-1.0.0-rc.2-arm64.dmg` and drag Sidekick to the Applications shortcut. Quit any running copy before replacing it.

This is a **prerelease**. The existing [v1.0.0 release](https://github.com/Sakzyo/Sidekick/releases/tag/v1.0.0) remains available.

This build is **ad hoc signed and not notarized**. It has no Apple Developer ID signature, so macOS Gatekeeper may block a downloaded copy. Verify the download with the accompanying `.sha256` file:

```sh
shasum -a 256 -c Sidekick-1.0.0-rc.2-arm64.dmg.sha256
```

## Validation and known limitations

- Release arm64 build, nested code signatures, disk-image integrity, and the mounted app's version and architecture are checked before publication.
- Blank message bodies were observed during automated screenshot capture of the preceding Debug build. This packaging update does not include a renderer fix; full conversation, model, and tool workflows have not been revalidated for RC2.
- The inherited in-app updater still uses the original project's feed. Download this fork's builds from its GitHub releases.

## Build and package

Build the `Sidekick` scheme in the `Release` configuration for Apple Silicon, then run:

```sh
./scripts/package-dmg.sh /path/to/Release/Sidekick.app
```

The script signs the staged app and its nested code ad hoc, verifies the signatures, includes these release notes and an Applications shortcut, verifies the DMG, and writes a SHA-256 checksum under `dist/`.
