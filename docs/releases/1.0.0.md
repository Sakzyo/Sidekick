# Sidekick 1.0.0

Build 39 · Apple Silicon (arm64) · macOS 15.0 or later

## Changes

- A quieter chat interface inspired by Codex, with a wider sidebar, centered conversation content, and refined message styling.
- Model selection inside the chat textbox, alongside Search and Functions. The picker remains accessible with Command-K, and the controls wrap when space is limited.
- A simpler toolbar with expert navigation in the expert menu, plus a clearer new chat screen.

## Download and install

Open `Sidekick-1.0.0-arm64.dmg` and drag Sidekick to the Applications shortcut.

This build is **ad hoc signed and not notarized**. It has no Apple Developer ID signature, so macOS Gatekeeper may block it when downloaded. It is intended for users who accept that distribution limitation. The accompanying `.sha256` file verifies the download's integrity.

## Build and package

Build the `Sidekick` scheme in the `Release` configuration for Apple Silicon, then run:

```sh
./scripts/package-dmg.sh /path/to/Release/Sidekick.app
```

The script signs the staged app and its nested code ad hoc, verifies the signatures, creates the DMG with an Applications shortcut, verifies the disk image, and writes a SHA-256 checksum under `dist/`.
